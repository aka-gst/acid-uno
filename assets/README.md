# Картинки

Кладутся сюда как есть. Игра проверяет каждый файл сама и,
если его нет, рисует прежний вариант кодом — поэтому можно
класть по одному и смотреть, что получилось.

## Что куда

| Файл | Что это | Формат |
|---|---|---|
| `arena-1.webp` … `arena-4.webp` | фон стола | 1672×941 |
| `bot-1.webp` … `bot-8.webp` | портреты соперников | 512×512 |
| `card-back-1.webp` … `card-back-4.webp` | рубашка карты | 512×768 |

Формат везде webp: при том же качестве он вдвое легче jpg и
png, а весь набор укладывается в восемьсот килобайт.

Порядок портретов — как в docs/prompts.md: Мелодичный Джо,
Вафельная Элли, Хмурый Барнаби, Ленивая Марго, Пыльный
Освальд, Скрипучий Тим, Стеклянный Юджин, Колючая Дафна.

## Что происходит без файлов

- фона нет — остаётся координатная сетка, нарисованная кодом
- портрета нет — остаётся экран с осциллограммой
- рубашки нет — остаётся трилистник на чёрном

Каждый набор независим: можно положить только фоны.
