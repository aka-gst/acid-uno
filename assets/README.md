# Картинки

Кладутся сюда как есть. Игра проверяет каждый файл сама и,
если его нет, рисует прежний вариант кодом — поэтому можно
класть по одному и смотреть, что получилось.

Что и как просить у генератора — в `docs/prompts.md`.

## Что куда

| Файл | Что это | Размер |
|---|---|---|
| `arena-1.webp` … `arena-16.webp` | фон стола | 1672×941 |
| `bot-1.webp` … `bot-24.webp` | портреты соперников | 512×512 |
| `card-back-1.webp` … `card-back-12.webp` | рубашка карты | 512×768 |

Формат везде webp: при том же качестве он вдвое легче jpg и
png, а первый набор из шестнадцати файлов уложился в
восемьсот килобайт.

**Номера идут подряд, без пропусков.** Проверка перебирает
их по порядку и останавливается на первом промахе, так что
`arena-7` без `arena-6` не увидят обе.

## Портрет привязан к имени, а не к месту

(`src/rules.js`), а не N-го стула. Ржавый Кларенс ржавый за

совпадёт само, править ничего не нужно.
